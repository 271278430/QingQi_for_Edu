# 教学图标注、精确读数与响应耗时

输入 → Store身份/请求准入 → 原题与小问绑定 → 按需识图 → 教学Loop/受控数学工具 → 核验 → Store提交 → Web图示与对话。

固定几何族的通用符号恒等式是进程内不可变计算缓存，不是学生记忆。服务就绪前初始化，Registry直接调用也保证准备完成；每道题仍校验身份、参数、分数与符号结果，返回独立对象。正常工具deadline保持不变。恢复成功清除当前错误投影，历史失败事件保留。

GLM-5.3-Flash真实API以1210拒绝thinking.disabled，说明始终思考，只支持low/high/max。转写使用low，不更改用户持久化模型配置，不把其他模型的关闭思考参数照搬进来。性能优化来自避免重复视觉转写、重复上下文和冷符号计算；不以截断输出或未经授权切换模型提速。模型耗时与首段可见正文耗时分别记录。图片上传/读取/符号核验通过SSE进度反馈；临时用户输入与流文字不是接受历史。

数学教学默认主动提供与原题当前问相关的图或动画。纯寒暄、缺必要条件或明确不要图时不造图；默认苏格拉底的图不泄露最后解法，按原有教学许可检查。几何默认画构造图，概念和函数复用已有受控模板与同一个render_teaching_visual入口。

多问路由保留不带新小问引用的后续修饰：“第一问完整答案，并配合动画”归第一问；并列引用组共用本组后续修饰。跨问的答案许可不传播。图示开头的样式/长度指令可以应用各问，不能从样式前缀复制给答案许可。标注引用的当前问由所选图标题/教学目标确定，用户明确指定的小问优先。

真实标注回放发现“不要给完整解答”被误识别为正向“完整解答”，导致分步长解和答案许可。否定范围必须包含邻近的“给/给出/告诉我/提供”等命令词，完整解答、解法、解题过程和最终答案都适用；同一小问的否定不被完整讲解关键词反向授权。只要求解释辅助线依据时，默认简短说明后继续苏格拉底引导。其他小问的明确答案请求仍独立生效。

几何构图按具体小问绑定：第一问中点图不能使用第三问的分点比例；一般比值/函数图保留自己的参数。多问共用一次绘图调用，优先明确请求的视觉形式，合并重复构造，最多两图；完整动画许可只属于对应小问。旧中点图只读修正显示，回连线读取同一显示投影。几何示意图按点的边界铺开，绘图坐标折叠且注明精确形式；坐标题保留坐标轴和读数。标注保留原题库assignment引用，本轮不计分。

Web图和动画可暂停当前帧并标注：自由曲线、直线、圈选、文字标记、颜色、撤销/重做/清空。标注在独立草稿画布，原图/动画数据不改变。返回对话导出PNG，复用ZCode附件序列化与现有三图上传；返回本身不调用模型，发送后才讨论。

连续绘制稳定性：指针事件回调内立即读取画布坐标和指针身份，React延迟状态更新只捕获不可变坐标，不读取已失效的event.currentTarget。连续快速移动、长曲线采样、快速抬笔与取消不会卸载工作台或清空原图。草稿仅接受当前指针；取消或丢失捕获时终止该笔，保留既有笔迹。画布刷新合并到浏览器帧，返回PNG前同步刷新，保证导出的笔迹和屏幕一致。验证通过真实按下指针后批量派发move/up模拟React批处理，而不只依赖逐个等待鼠标事件的慢速验收。

标注附件携带visual_context(run_id,visual_index)。Store只允许同学生、同会话的已完成教学图。原题来自该接受记录，标注是待讨论的学生证据，不重新OCR为另一道题、不推断学生已掌握、不计练习作答；图片直接交视觉导师讨论，避免重复转写。原题与当前问/已核验数学观察作为上下文，标注不能授予答案许可或改变源条件。切会话、关闭/取消、返回失败不能落到另一会话；网络失败沿原请求编号恢复。

数值画图用浮点，显示独立：工具按源分数参数推导的坐标使用精确分数/根式标签；运动中间采样只显示带≈的简短测量。不能由任意浮点猜一个根式宣称精确。原静态几何图的点标签由源构造再计算，不修改原接受历史；正文、坐标说明、数轴和动画读数检查长小数。
