第（1）问：读中点与直角 → 连接CD，标注AD=CD与垂直 → 绕D顺时针旋转，画A′/C′/E′及A′C′ → 识别A′=C、C′=B、E′=F → 对应边及DE=DF。辅助线随步骤显示，不声称旋转中点始终在原边上；对应边使用同色和同类标记。提示模式只给观察线索及局部变换，不提前给完整证明和最终式。

第（3）问：读比例与长度定义 → 用等价坐标明确D、E、F → 列点积为零并整理函数 → 动点与函数坐标同步变化 → 合并E在边内部及F在射线上的范围。BC从B经过C继续延伸，用箭头和延长段表示；不能只画BC线段。范围开闭由数学条件决定，不把E端点当合法位置。抽样动画不替代证明。

第二问的长度比使用同一动点模板的ratio目标：固定分点比 → 坐标表示 → 垂直条件求交点 → 比较距离平方 → 由正长度得DE:DF=m。动态图是一个已绑定m值的例子，公式说明对任意正m成立，不能用单例测量代替全称证明。

初中场景默认改用垂足与相似，不要求学生掌握向量点积。第二问：作垂线得H、K → 两组对应锐角相等 → 直角三角形相似 → 长度比；E=H、F=K时直接比较垂距，不能把退化三角形称为相似。辅助点名称避开原六点。第三问先确定AH、BK，再根据E在H两侧列BF=BK±KF，两种位置化简为同一函数，重合位置单独说明。后台坐标仅用于符号核验，前台采用初中几何解释。
