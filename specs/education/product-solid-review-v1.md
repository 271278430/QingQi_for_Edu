# 学生Web产品完整审查与整理

范围是当前教育产品的四功能、设置/模型/架构、HTTP/Store、数学与图示、ZCode运行适配和启动维护。固定ZCode 3.18.2教育分支；上游4.0整批升级另行适配，不混入此次产品审查。

## 产品规则

- 教育界面统一中文，移除只翻译导航的语言切换；共享ZCode Intl继续为原组件提供中文。保留主题切换。
- 学生首屏显示当前任务、必要行动、反馈和学习依据。去除重复学习空间徽章、固定宣传说明、空复测指标和重复覆盖说明。
- 图片、题干、当前小问必须可见；识别全文是可展开的校对依据，默认收起。题目来源与详细证据保留在展开区域，错误和题目质量问题始终可见。
- 学习地图仍是一张可选路线图；看板保留摘要和图谱；推荐始终三题且实际选择影响练习。以上核心入口不得因简化而被隐藏。
- 手机导航支持按钮、Escape和点击遮罩关闭；平板/桌面侧栏常驻，不显示无作用的打开/关闭按钮。主导航注明当前页，图标按钮具备名称。

## 状态与时序

Store拥有唯一已接受的会话、学情、设置、配置和调用账本。Web只保留草稿、待确认命令和展示状态。

系统设置的GET与POST通过version协调：已接受POST推进本机acceptedVersion；更旧GET丢弃；同版本GET不抹掉输入草稿。明确409后重新读取当前版本，未知结果冻结同一命令重试。成功通知父级，即使设置页已卸载；已完成历史清理同样通知工作区失效旧投影。

切换会话的读取过程锁定输入；session、题目参照与预填草稿在同一确认结果中更新，不能读取未完成时把新输入发给旧会话。generation/selection拒绝迟到结果，读取失败保留原会话。学习操作成功提示只属于当前视图，换页清除提示，避免挤占手机图谱首屏。

学习路径、看板、练习共享一个LearningPanel生命周期和学习快照；换页保留未提交答案和待确认命令，迟到结果更新数据而不抢回导航。学习提交以同步inFlight ref防止同一界面事件周期重复受理，服务端幂等边界保持不变。

```text
UI草稿 → 原命令编号 → Store校验/事务 → accepted version → 当前Web投影
                                      └→ 父工作区通知（不受子页卸载影响）
旧GET ── 版本低于已接受版本 ── 丢弃
学习页切换 ── 同一学习生命周期 ── 保留草稿，结果不抢导航
```

## 工程与验收

HTTP客户端将断网和非JSON网关错误转换为中文的稳定错误类型；不得把HTML响应或SyntaxError展示给学生。保存结果未知时仍保留原命令，刷新与重试能够恢复，错误格式处理不能生成新编号或绕过权限。

建立一份当前验收清单，覆盖数据、学习证据、推荐/路径、辅导/记忆/图片、精确数学/图示、模型、权限/历史、运行适配、启动和Web。受控端点、真实模型样例、正式入口检查分开标注。旧格式验收有明确替代入口，不把过时断言混成当前产品失败。

新浏览器场景先维护，再修改实现：中文一致/必要入口、平板/手机导航、按页保留答案、旧GET不能回滚保存、同版本读取保留草稿、离开设置页后的保存通知、空状态/遮罩、桌面/手机/浅深主题。既有图片、同题、按问流式、数学动画、三题和恢复场景继续运行。

整理前后比较生产SQLite逻辑内容、配置和索引指纹。仅清理明确可重建的测试目录与缓存；生成证据在.local，源码/规格/文档纳入可恢复的本地Git基线，凭据、学生历史、原始数据和依赖不入库。

复合任务完成所有必需工具后，主控仅接受候选回复/澄清，移除此阶段不再可调用的工具契约，避免重复Schema挤占输入预算；保留本轮已核验观察和引用。48KB网关上限及模型上下文边界不放宽。

由原式编译的故事数学关系不可交给通用润色器改写。继续故事超过本轮文字预算时使用同一编译器的短版账本，保留角色、原系数、条件与当前一步；可选开场模型失败仍交付正确场景，不重复该未知/失败调用。未明确要求答案的动画和自然追问保持默认苏格拉底，不能由旧验收要求复述已公开答案。
