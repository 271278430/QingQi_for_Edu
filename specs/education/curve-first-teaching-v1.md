# 围绕原题的函数图教学

2026-11-23。用户反馈推理动画仍不直观。已确认提示静态图改了原题系数，且已支持的函数题仅在绘图关键词出现时绘图。改为主动选择与原题目标相关的曲线。

## 输入到输出

原题/图片转写 → Store 当前题归属 → 教学决策（提示范围、明确否定、是否已公开答案） → 原题符号工具 → 图示工具校验/编译 → 同一回复事务 → 曲线与公式/唯一播放器。

函数与非负和的编译器拥有数学事实和图形数据；teaching_plan拥有本轮推荐与许可；visual_task沿现有Agent Loop执行一次图示工具。UI只投影已批准曲线，播放、放大、单步沿用useTeachingAnimation。自动图示不得把提示改成直接答案或声称学生已掌握。

## 图形选择

- 已支持的唯一正零点函数题主动附原题曲线，不要求用户说画图。完整解答的第一屏即能看到已确定函数、零点、最值区间和合法候选点；动画依次解释相切、消元、导数、最值。三种参数情形用一个大图切换，避免三张缩小后无法读的图。
- 提示版保留原题k、c和区间。未知参数的曲线明确说明是原题函数族，横轴以尚未求出的r为尺度并使用符号刻度；不显示求得的参数、根的数值、最值或最终所求。静态提示可用原题参数取0的试探曲线，但必须注明它不满足零点条件、不是确定解，不能换k/c/区间。
- 完整非负和题主动使用对应根式/绝对值曲线，展示定义域、非负范围、零点与正值的矛盾，不再使用无关积分柱。提示版横轴为原题内部一次式，避免泄露已求变量；完整解答可展示原变量轴与精确零点。两条横轴明确独立，不把a和b当成同一个自变量。
- 明确不用动画时输出静态曲线；明确不要图时保留文字教学。普通无关问题不强制添加图。自动图示仍遵循本轮答案许可，显式提示不被自动绘图覆盖。

## 图示契约

ReasoningCurve新增可选formula、axis_labels、x_ticks、y_ticks、note，由工具提供精确/符号标签。function_plot扩展受控square_root与absolute（内部ax+b），复用原采样工具和FunctionFigure，定义域与曲线标记需核验。模型不能提供脚本或自定义采样。非负和静态数据仍由当前题编译器批准，沿原validate_binding校验。

## 验收

真实图片还暴露一个阻断：完整“函数、唯一正零点、区间、最大最小值之和”题干被OCR仅因选择题选项未截入而标unclear。识别提示须区分必要条件与可选选项。受控恢复只用于已完整识别的上述数值目标，且note只涉及选项/冒号；有看不清、系数不确定、遮挡、条件缺失等证据仍保留澄清，不猜原图。恢复不补任何题干，也记录“选项不影响完整数值目标”的来源。

先维护现有隔离HTTP/浏览器场景：没有绘图口令也能画原图；显式不要图/不要动画；提示不换系数/区间或泄露答案；完整解答第一屏实际函数曲线；数值刻度与精确关键点；三种情形可切换、导数联动、候选点与最值；非负和真实曲线及正值矛盾；负系数定义域、分数零点、不同题/续聊、缓存重放不写成绩。实际图片GLM验收、浏览器目视检查、根类型/Lint/Hooks、构建、架构门禁与两正式入口只读检查。生产历史与题库不作为写入测试对象。
