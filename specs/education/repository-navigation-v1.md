# 仓库分类与目录说明

清启是基于 ZCode 开发的学生端教育 Agent 项目。项目介绍使用这个定位，准确区分 ZCode 基础模块和本项目的教育业务，不用“复用”作为项目介绍。

education 保存学生产品。service、runtime、client、web 各自负责教学状态、运行能力、通信契约与页面交互。tools 保存启动、导入、资料制作与维护入口；tests 独立保存验收、浏览器场景、夹具和真实服务探针，review_all 从同一清单运行这些场景。两目录保持同一层级，原来的资源路径、源码根和数据根不变；跨目录导入明确指向 tools。

apps、packages 等 ZCode 基础目录保留包路径和许可证。根 README 按产品、基础、工程、文档与第三方资料说明入口；GitHub About 介绍四项学生功能。旧的源码来源说明改名为 zcode-foundation，保留实际模块、版本与版权事实。

每个包含版本化文件的目录都需要 README，介绍目录用途、直接子目录和每个直接文件的简要职责；递归阅读子目录覆盖全仓库。已有正文和版权保留，只维护有标记的目录索引。说明不覆盖 node_modules、运行数据库、凭据、缓存与本地报告，也不将这些文件列入公开索引。

已登记精确哈希的原始 README 保留为同目录的 UPSTREAM_README.md，字节不变；新的 README 提供项目目录索引，原始资料登记同步调整路径并保留原哈希。这样目录说明与原始资料各有明确入口。

目录索引从 Git 文件集生成，只写 README，不移动或改写第三方资产。文件描述优先使用教育模块的明确说明、包元数据、模块注释和公开符号。检查覆盖率、链接、漏列文件和过期条目；运行本地构建、当前验收清单与远端 CI 后发布。
