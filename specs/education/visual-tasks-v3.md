## 教学策略

mode 保留兼容字段；实际教学计划拆成 content_style（brief_hint / micro_explanation / stepwise / worked_solution）、interaction_style（guided_question / independent_try / direct）及 allow_final_answer。逐步讲解描述内容组织，苏格拉底描述学生参与方式，两者可组合。显式“逐步苏格拉底”使用逐步引导：每轮只处理当前一步，简短依据加一个学生推理任务，不一次给整题解法。明确“不要反问”改为直接解释，不必再让用户选模式。答案权限独立处理，组合策略不隐式授权最终答案。

组合策略使用解释级别的有界预算，非纯提示预算；仍按难度、学情和简短要求调整。目标是一个思考任务，可包含两个相关子问。budget.questions 是目标，review_questions=2 是聚焦改写阈值；只有明确零追问时 hard_questions=0，其余为 null。超目标记录质量指标，超过改写阈值时只进行一次自然文本聚焦改写，不共享领域错误的协议修复循环。改写仍须通过答案权限、题目绑定和图示真实性校验；不合格改写保留原来的已校验文本。仍超过目标时记录待改进质量，不能仅因问号数量让教学回合报502。展示标签反映组合策略，而非仅由末尾问号或教学动作重命名。

绘图回合的零追问是本轮展示策略，不写成学生长期“不要反问”偏好。通用题的对话/画图次数不能作为解题阶段推进证据；只有实际核验作答才可推进已定义的步骤，提示次数只用于支持强度与重复卡点判断。

## 图示工具

沿用唯一 render_teaching_visual、ZCode Registry/Executor/Schema/Skills。新增专门的 VisualTask 规划与可信编译模块；当前点连接能确定性完成，无需新增自由自治绘图子 Agent。主模型选择复杂模板；工具负责数据几何计算和实际图形。将来视觉子任务只能输出此契约，不能生成可执行网页或改写学生事实。

coordinates 新增有界 segments、polygons、circles：端点必须引用已有点，线段区分实线/虚线及边/对角线/辅助线；多边形顶点、圆半径均校验。题面坐标按整对匹配，不能从零散给定数拼造点。相似例子明确标注。

新增 function_plot（线性/二次系数，工具采样）和 area_model（分数分区矩形/圆）；动画新增 coordinate_drawing、fraction_fill、pythagorean。动画关键帧、函数采样和面积由可信工具计算；模型不供应 SVG/JS/关键帧。几何连点默认只连接已知点，不能偷偷补出原题所求顶点。

明确的 y=一次/二次表达式与分数 a/b 直接解析为绘图参数，图必须对应用户原式，不能用另一个示例替代。表达式只使用有界多项式AST解析，不执行代码；未支持的函数类型明确澄清。通用“给一个例子”仍由模型选择模板。连接角色在源题明确正方形且距离关系符合时区分边/对角线，否则仅表示普通连线，不将斜线自动当对角线。

明确表达式使用 problem 来源：函数按原式展开后的系数核验，不能用数字白名单代替代数一致性；分数按原分子分母核验。来源显示“依据当前表达式 · 工具计算”。中文紧邻 y= 也须解析；超出一次展示的两条函数上限须澄清，不能截掉需求。普通连线 role=connection，正方形按距离关系识别边/对角线；默认先边后对角线。连线动画在两个关键帧之间连续延长当前线段，单步仍停在完整线段处。

## 当前图的修改与真实执行

Store 是当前图上下文唯一来源：按学生、会话及当前原题/图片归属读取最近已提交图。取消、换题或摘要过期后不跨任务借图。新修改作为新的助手消息保存，旧消息保留。parent_id 只作已接受图的来源引用。

“把点都连起来”是实际绘图命令。明确点序则按序连接，否则连接已有点的所有不重复点对；超过工具上限则先澄清。读取现有点或题面坐标后，由同一工具执行；要求动画则按线段次序逐条画出。不能用“想象连接”替代动作。缺少点时说明需要坐标，不声称完成。

只有工具已经返回真实连线/动画，才能说“已画好、已连接”。模型的图示完成声明须对照本轮工具结果；必须绘图的请求不能只返回文字。坐标标签去掉同一坐标的重复后缀，刻度用易读间距。

纯绘图任务完成后直接用工具结果生成简短完成说明，不再额外请求模型润色，以免正确图形被可选文字的格式错误拖成失败。需要教学解释时仍由模型处理并校验。完成说明只报实际点/线数量或图示类型，不推断解题答案和学情。

Web徽标读取最终教学决策，不再仅把ask统一显示成启发式追问。进入实际对话后原题默认折叠，学生仍可展开。消息区与输入框有明确flex边界；懒加载图形增高时跟随底部，学生主动回看历史时停止跟随，避免只看到图的一部分。浏览器须核对图中点位于实际消息视口内，不能仅检查DOM存在。

教育MathContent仅在几何语境将短大写名称（AB/ABC）映射为明确TeX命令，避免上游为保护美元/环境变量而保留字面美元符号；代码块和行内代码不转换。截图中的$AB$、$BC$必须浏览器验证实际数学渲染。

真实模型复测发现工具ID被写成 Markdown 图片URL（visual:...），以及行内公式结尾重复美元符。当前真实工具ID的图片引用在提交前移除，图仍由结构化结果展示；不存在的ID拒绝。重复的“图示：...”占位说明不再代替或重复真实图。MathContent仅在明确的行内公式结束且后接标点/空白时去除一个重复结束符，代码和块级公式保留。

图示参数、结果、策略与文字仍在同一 run 的检查点和原子提交中保存；已有工具结果的恢复不得重复执行。播放和观看不计分。新图示版本与契约签名参与恢复检查。

## 验收
