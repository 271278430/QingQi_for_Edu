# 当前任务、原题引用与学生工具

当前用户消息决定本轮任务，原题、图片、历史教法和图示只是可引用上下文。推荐类似题、查看学情、查看或预览学习路径，不因存在旧题而改成解题；这些任务不继承旧题的情景或动画要求。只有当前同时要求讲解时才执行教学，教学方式仍由既有字段管理。

以 Codex 开源引擎的 TurnInput、RegularTask、ContextManager、ToolRouter、ToolOrchestrator 和工具结果事件为设计依据，保持本项目的 Python Store 与 ZCode Node 执行基础。当前任务形成有类型的计划，原题形成单独的引用；计划决定工具，工具结果决定可展示产物，不能用“我已推荐”的文字代替真实题目。

明确操作走快速规则；存在学习操作线索但规则未识别时，在绑定旧题之前交给既有 LayeredRouter（可配置主模型的 Schema 分类）。分类仅能选择已登记学生任务；参数仍由原始输入与所属资源绑定。查询任务不调用教学模型，复合教学保留原教学链与 DAG 顺序。

新增固定只读工具 recommend_practice、preview_learning_path、read_learning_dashboard。工具参数由当前请求和所属资源绑定，不接受学生身份或任意路径；Python 回调通过同一 Store 读取，Node 只注册和执行。只读查询不更改目标、路线或成绩。曝光记录在接受回复时与回复共用事务，每个请求只提交一次；未知调用结果保持原账本。

推荐从完整、同年级且可核验的题库中选择，结合原题知识、结构、学情难度和近期曝光。明确“一道”返回一道，“三道”返回三道，未指定默认三道，上限三道。排除原题和相同题干；供给不足如实说明，不用无关题补数，不透露答案或分析。没有原题也没有知识点时只询问必要信息。

推荐结果是候选题，查看不会自动开始练习。点击题卡沿既有练习入口选择；对话中明确引用“刚才推荐的第一题”时，绑定该会话已接受的候选并在接受教学回复时创建同会话练习。选题与作答仍由 Store 管理，不把推荐或讲解计为独立完成。

纯查询任务保存为本轮任务结果，保留原题、教法、答案许可和未完成步骤；它不续期旧的临时教学状态，也不能在后续恢复中被当成新题。原题教学历史跳过非教学任务，避免查询后续不上旧对话。多意图请求保留明确的教学与查询需求；否定、引用和题干中的“推荐”等词不触发工具。

明确取消或开始新题同时结束隐式推荐来源，不能从历史候选偷偷恢复已结束的任务；保留历史题卡，学生可以显式点选。

Web 使用 student_tasks 判别结构展示真实题卡、学情摘要或路线预览，与已有 SSE 和历史恢复共用协议。工具失败和无候选不会降级成旧题讲解，重放不再次曝光或调用模型。

旧版已接受但没有执行查询任务的回复只读标记为“任务未完成”，原文折叠保存；重新推荐是学生明确发起的新请求，不改写旧记录或沿用旧编号。查询时新上传的图片作为资料保存，随后明确引用“图里这题”时使用最新同会话图片资料；普通“回到原题”仍引用原教学题目。

验收：截图原句、同题旧故事偏好、换一题、明确数量、否定与题干引用、英语请求、直接指定知识、无原题、无供给、更新学情、连续推荐、缓存、不同会话、图片上下文、复合讲解/推荐、候选选择与之后续聊、刷新、手机和工具错误。完整当前回归、类型、Lint、Hooks、构建及正式数据保护必须通过。

公开演示用自编题库验证对话推荐、原题排除与模型零调用，不依赖私有教材、学生资料或真实密钥；已有模型配置也不能让纯推荐转入教学生成。
