## 目录与文件

清启是基于 [ZCode](https://github.com/zai-org/ZCode) 开发的学生端教育 Agent 项目。

Python 教学服务；接收 Web 请求，执行教学循环，核验数学结果并维护学生状态。

### 子目录

| 目录                            | 存放内容                                     |
| ------------------------------- | -------------------------------------------- |
| [config/](config/README.md)     | config 模块文件，属于 education 目录。       |
| [examples/](examples/README.md) | examples 模块文件，属于 education 目录。     |
| [skills/](skills/README.md)     | skills 技能指导和资源，属于 education 目录。 |
| [src/](src/README.md)           | 教学服务的 Python 包目录。                   |
| [tests/](tests/README.md)       | tests 验收与回归场景，属于 education 目录。  |
