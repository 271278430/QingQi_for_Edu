# 对话选模与推理档位 · 2026-11-25

新对话默认高档；低档由学生在输入框手动选择，恢复已存的低档会话不覆盖。文本和图片角色分别可选择已经配置的模型，同一多模态型号也可用于两个角色。识图不再强制降档。

实际复用的源码是`packages/ui/src/ModelConfigSelect.tsx`及其`ComposerModelMenu`，包括供应商分组、推理滑条与焦点恢复；`education/runtime/src/model-options.ts`通过shared公开出口调用原`packages/model-option-map/src/compiler.ts`，执行受限CEL映射。发送快照参考原`composerSubmissionConfig.ts`，在教育请求中携带模型身份、配置版本与档位。教育界面与后端的学生/会话隔离由本项目实现。

ModelSettings/Store仍拥有连接与凭据；ChatModels使用同一版本化表的隔离namespace，只有角色选择，不复制凭据。学生菜单只读安全目录，保存经CSRF、会话归属、版本和幂等准入。提交时核验启用状态、图片能力、凭据、档位和模型版本。CEL输出只允许reasoning_effort/thinking，不能改地址、认证、模型或消息。全局配置与会话客户端从同一事务快照读取。

首次发送先创建实际会话与冻结选择，再上传图片；图片上传期间预选下轮配置写实际会话。当前生成中仍可预选，当前回复使用原发送快照。明确重新回答用新编号与当前选择；原编号恢复保留旧配置和原题标注。保存/读取冲突时停止发送并保留草稿。

回归发现添加文本菜单会让原Flash入口误用GLMController处理取消和数值任务。现在Agent.text_model仅提供文本导师客户端，原Flash继续使用OfflineController与本地LayeredRouter，两个角色仍进入同一deadline、账本和流式观察。模型选择不更改教学教法，也不额外授权答案。
