# 统一模型配置

模型适配现在只有供应商与型号编辑器。原“教学模型”角色区域已删除，默认文本、图片和当前已配置的专项用途直接放在型号卡片上；点击后由同一Store命令立即保存，无需第二次“应用”。

服务启动时将本机已有连接、型号、能力、90秒超时、Token预算、推理参数及凭据导入已有配置库。导入保持型号ID与已有默认选择，自定义连接和会话选模保留。部署凭据在本机加密，接口不回传明文；导入后连接可编辑，读取与重启不再覆盖已保存配置，删除后也不会重新注入。

单角色用途命令只修改指定角色，图片用途仍校验图片能力，两个角色可共用一个多模态型号。可选8B/27B用途可以取消，取消后运行层不会再从部署文件回填该模型。生成中的客户端保留已冻结配置，下一轮读取对应会话和型号的当前版本。

配置页、对话模型目录与实际客户端沿同一模型投影。引用来源被删除或变更时，受影响型号标为不可用，配置页仍可打开和修复；身份权限与凭据不可用分别处理。

源码入口为`model_deployment.py`、`ModelSettings.sync_deployment/select_role/resolve`以及Web的`ModelUses`和原ZCode供应商/型号编辑器。没有新增另一套模型状态或保存接口，旧批量选择协议仍兼容。

验收覆盖导入与重启、用户配置优先、密钥保留、失效引用、真实HTTP参数、单角色用途、模型编辑和测试、刷新、对话选模与手机布局。最终结果见[验收说明](../verification.md)；正式配置同步仅修改模型配置库，教学历史和画像保留。
