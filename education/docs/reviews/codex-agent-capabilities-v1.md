## 明确的状态边界

Store 是唯一可写的接受状态所有者。Web 持有未提交草稿和在途引用；取消作用域只监听 Store 信号；Node 只执行已授权动作。三者不另建接受队列或学情缓存。

停止保留输入、图片及可见片段。可见片段不计成绩或教师事实，但属于帮助曝光，后续答对不能冒充独立完成。主动停止不显示为系统错误。模型服务可能已经接受请求，客户端断开不能保证供应商停止计费；结果未知时保持账本状态，不静默重发。
