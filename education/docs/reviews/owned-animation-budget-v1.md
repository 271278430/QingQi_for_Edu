# 当前题动画请求修复

2026-11-27。用户在已有相反数练习中请求“给我一个动画帮助理解”，服务返回 `model_truncated`。该轮账本确认：输入约13,110 token，输出上限1600；供应商报告1598 token用于推理，正文为零，工具调用为零。

`Store.prior_visual`原来只返回坐标连线图，普通数轴图被忽略；泛化动画要求没有编译成已知动作，模型收到完整图示Schema后重新选择场景。已有测试覆盖显式函数与几何动画，漏掉了“当前题＋既有图示＋最高推理＋短输出额度”的连续会话。之前的通过不能证明这个场景正确。

修复沿同一Store、Agent Loop、ZCode Registry/Executor和调用账本执行。Store按身份、原题和当前问读取已接受图示；`visual_followup.plan`将已知关系编译为有限动画；原Schema、题面和答案许可核验后执行，再采用批准的简短回执。没有额外模型润色才能交付的依赖。

相反数动画展示同步展开的对称点、等距线段与和为零；函数、字面坐标和面积图可同源转换。几何旋转与比例小问仍由原符号Controller构造，不能拿旧连线代替当前问的推理。通用函数动画也不再套用另一道“唯一正零点/区间最值”题的解说。

仍需模型选图时，`visual_model_contract.select`仅缩小原Registry的可见Schema分支。授权和执行核验继续采用完整原合同，不扩大权限。参考Codex固定提交 [`af71942309704997f4bdc86c020717646423c080`](https://github.com/openai/codex/tree/af71942309704997f4bdc86c020717646423c080) 的 [ToolRouter](https://github.com/openai/codex/blob/af71942309704997f4bdc86c020717646423c080/codex-rs/core/src/tools/router.rs) 与RegularTask生命周期，教育数学编译由清启实现。
