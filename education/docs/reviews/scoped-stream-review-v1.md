# 分问与流式教学修复记录

2026-11-23。两个正式入口已重启，页面、健康接口与构建资源返回200。

## 截图中的问题

原实现把整句选成一个教学模式，再把所有提到的小问汇总解答。“直接给第二问答案，然后开始第三问教学”中的答案许可因此传到了第三问。历史的整题answer_disclosed也可能把后续教学自动切回解答。

现在tutoring_scope按小问和操作拆分有序任务，每段独立选择模式、校验并标注。第二问可以明确给解答，第三问默认苏格拉底；Store保存最后教学的小问和各问披露情况，下一轮不因前一问的许可给答案。概念/困难反馈可增加解释深度，但默认互动仍为苏格拉底。明确指定分步、启发式或直接答案时才选择对应方式。

## 输入到输出

原题/图片 → 同身份原题绑定 → 小问与操作识别 → 每问教学策略 → 同一Agent Loop/工具与模型 → 每段教学校验 → 一次Store事务 → 规范回复与会话记忆。

Web仍POST原/api/teach与同request_id，以Accept选择SSE。原模型网关使用提供方真实stream增量；内部推理、工具参数、OCR不发给学生。增量通过当前教学检查，修复或压缩时替换草稿；done才接管历史。确定性几何教师在生成、核验各问后发送相应内容，没有增加打字计时器。

还修复了两个浏览器问题：临时流独立于懒加载的历史消息组件；刷新时等会话Detail恢复后才允许发送，避免“继续”误建新会话。SSE有序号、请求编号、UTF-8解码、错误事件和同编号重放。学生的图片/草稿在失败时保留。
