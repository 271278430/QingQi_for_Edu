# 当前指令、记忆与教学数轴审查

清启是基于 [ZCode](https://github.com/zai-org/ZCode) 开发的学生端教育 Agent。2026-11-27，本轮检查修复了完整解答请求被教学偏好拦截、原题数值被圆整及数轴长标签重叠的问题。

## 根因与修复

“重新画一张图，并把这道题的答案全部给我”包含两个任务。旧答案规则漏掉了动词在后的语序，沿用了提示偏好；旧数值格式化又把题干2.061和已知近似1.436改成了两位小数。数轴把三个长标签放在同一高度，并无条件把映射距离显示为加法，导致排版和教学含义都有问题。

当前答案命令使用统一解析，许可和禁止按出现顺序处理，最后明确命令覆盖旧偏好。多问先合并整题命令及小问例外，再执行，避免先给答案后处理禁止。完整解答和重画分别完成；已有可信图可经本地工具重绘，图示回执不能遮盖参考解答。

原题数字保留原值。模型生成的未知长小数才作近似显示，不能将原题条件提前圆整后继续推导。模型上下文保留学生原话，排除已识别的错误根号近似或漏执行解答请求的旧导师说明；正式历史不改写，旧消息提供明确重执行入口。

数轴用P1…P8标识位置，完整标签在图内独立换行；近邻编号错开高度。M编号对应原映射和端点，不自动解释成加法。标注导出仍包含完整图内说明，短编号与原标签映射进入所属图示引用。

## Codex采用范围

## 验证

隔离HTTP覆盖原语序、当前否定、前后命令、引述历史、恢复时直答和整题/小问例外；浏览器覆盖长标签、八个近邻点、手机及标注返图。实际报告请求在正式库的独立副本重放，完整解答和一张重绘数轴同时交付，保留2.061/1.436，模型调用0次，不写正式历史或学生成绩。
