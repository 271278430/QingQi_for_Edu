# 上下文教学模式与讲解图 / 动画配对 · 2026-11-25

本轮替代此前“一律苏格拉底”和“默认只给一张图”的策略。当前意图、同题教学模式和真实学情共同决定教法；概念和为什么先解释，明确提示给可执行线索，明确追问或熟练迁移可用苏格拉底，持续困惑增加当前步骤的支撑。教学方式与答案披露分别管理，某问已经公开的结论可继续解释，不能扩到其他问，当前不提供答案优先。

Store.dialogue_state是teaching_mode的唯一持久化所有者。Agent准入后读取，teaching_policy产生本轮决定，Store.commit同事务保存回复、当前题、小问、模式及来源。图示经过原render_teaching_visual入口及真实ZCode工具执行链；teaching_visual_pair是受控的数学投影编译器，没有另建模型智能体、图片历史或播放器。模型适配和推理档位继续复用原ZCode组件与CEL映射，模式不会改变已冻结模型。

默认针对当前小问配对一张讲解图与一段动画。静态图强调条件、关键曲线或关系；动画展示原题的构造、变量变化或推导，并能连续播放至结尾。函数、非负式、恒等式和几何使用现有可信编译器。reasoning_diagram的单独静态请求也核对规范来源及披露，不能通过改参数偷换原题。标注快照合成完整多幅SVG，仍通过原图片上传和所属图示引用返回对话。
