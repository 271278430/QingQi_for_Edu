## 从输入到输出

Web收集文字、最多三张图片或所属历史题，并携带会话、请求编号和本轮模型选择。服务端先校验身份、来源、CSRF和资源归属，再由Store接收请求；已经完成的编号重放原结果。

辅导恢复原题、当前小问、同题教学方式和授权记忆。路由按当前意图、困难与学习证据形成教学计划；正文长度、互动方式与答案许可分别控制。

Agent Loop在预算内反复执行：决定直接回复或调用受控工具，登记调用编号，执行并核验工具结果，保存观察/检查点，再回到决策。候选回复核对原题、数学、归因、披露和图示；通过后Store同事务提交，失败可在预算内修复，结果未知或预算耗尽停止。

SSE正文是临时投影，done后Web采用已提交历史。下一轮从同一原题继续；图片标注仍是待讨论内容，不变成题目条件或成绩。

## 模块与唯一所有者

| 层         | 模块                                                  | 范围                                                         |
| ---------- | ----------------------------------------------------- | ------------------------------------------------------------ |
| Web交互    | web                                                   | 四页面、输入草稿、附件、播放与标注；只使用公共HTTP/SSE契约   |
| 请求与管理 | permissions、management                               | 身份/来源/资源准入；设置、模型连接、版本化清理与只读架构     |
| 学生业务   | tutoring、path、dashboard、practice                   | 连续辅导、可选路线、证据看板、每次三题与核对                 |
| 智能体运行 | loop、routing、memory、skills、tools、models、visuals | 决策回路、有界上下文、有限能力、协议推理、精确图示           |
| 数据与状态 | data、persistence                                     | 只读图谱/题库；唯一Store事务、租约、账本、学习事件与规范投影 |

学习路径依据真实先修、学情与可练题生成；共现不作为已确认先修。看板读取Store事件派生的同一快照。路线选择、提示、曝光和作答影响后续推题，提示后的成功与独立作答分开。

“给我一点提示”限定本轮hint_only文字帮助，不要求学生回复、不生成卡片无法显示的图，也不改变学生在对话中明确选择的教学方式。对话导师仍按当前上下文决定追问、解释或解答。

## ZCode边界

工具注册、Executor、Scheduler、PermissionService、MCP、Skill和受控前台子任务使用ZCode公开源码入口。召回使用有界筛选合同；持久化由教育SQLite实现。供应商连接、模型行、元数据与对话模型菜单直接复用ZCode UI设计/组件。

Python拥有教育教学策略与接受状态；未导入完整编码Agent运行时，不把TF-IDF候选召回当校准概率。图谱、题库与学生证据均保留来源，模型配置存在不等于远端健康。

每个模块的实际文件、符号、步骤和接口由服务端目录投影，设置页点击节点查看；源码绑定检查只证明入口存在，运行行为由回归与实际接入验证。
