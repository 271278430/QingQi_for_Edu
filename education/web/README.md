## 目录与文件

清启是基于 [ZCode](https://github.com/zai-org/ZCode) 开发的学生端教育 Agent 项目。

学生 Web 应用的包配置、入口和页面源码。

### 子目录

| 目录                  | 存放内容                                                              |
| --------------------- | --------------------------------------------------------------------- |
| [src/](src/README.md) | 四项学生功能及设置管理的 React 页面、交互状态、图谱、动画与标注组件。 |

### 文件

| 文件                             | 简要说明                                                        |
| -------------------------------- | --------------------------------------------------------------- |
| [index.html](index.html)         | index 模块的资源或工程文件。                                    |
| [package.json](package.json)     | @qingqi/education-web 的包信息、依赖和开发命令。                |
| [README.md](README.md)           | 本目录用途、子目录与逐文件说明。                                |
| [tsconfig.json](tsconfig.json)   | 本模块的 TypeScript 编译、类型检查或构建范围。                  |
| [vite.config.ts](vite.config.ts) | 消息代码块直接使用 ZCode 现有文件图标；缺少公共资源会触发 404。 |
