## 目录与文件

清启是基于 [ZCode](https://github.com/zai-org/ZCode) 开发的学生端教育 Agent 项目。

ZCode 的共享 React 组件、消息渲染、模型配置、主题与交互基础。

### 子目录

| 目录                    | 存放内容                               |
| ----------------------- | -------------------------------------- |
| [src/](src/README.md)   | @zcode/ui 基础工程中的 src 实现源码。  |
| [test/](test/README.md) | @zcode/ui 基础工程中的 test 测试场景。 |
| [vite/](vite/README.md) | @zcode/ui 基础工程中的 vite 模块文件。 |

### 文件

| 文件                                   | 简要说明                                                                           |
| -------------------------------------- | ---------------------------------------------------------------------------------- |
| [AGENTS.md](AGENTS.md)                 | 本目录的开发规范、模块边界与验证要求。                                             |
| [components.json](components.json)     | components 的数据或配置定义。                                                      |
| [lucide-colors.mjs](lucide-colors.mjs) | 颜色类同时携带图标绘制信息，确保父按钮、嵌套颜色和 Tailwind 状态使用同一条继承链。 |
| [package.json](package.json)           | @zcode/ui 的包信息、依赖和开发命令。                                               |
| [README.md](README.md)                 | 本目录用途、子目录与逐文件说明。                                                   |
| [tsconfig.json](tsconfig.json)         | 本模块的 TypeScript 编译、类型检查或构建范围。                                     |
