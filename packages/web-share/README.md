## 目录与文件

清启是基于 [ZCode](https://github.com/zai-org/ZCode) 开发的学生端教育 Agent 项目。

@zcode/web-share 基础工程中的 web share 模块文件。

### 子目录

| 目录                  | 存放内容                                     |
| --------------------- | -------------------------------------------- |
| [src/](src/README.md) | @zcode/web-share 基础工程中的 src 实现源码。 |

### 文件

| 文件                             | 简要说明                                                                      |
| -------------------------------- | ----------------------------------------------------------------------------- |
| [index.html](index.html)         | index 模块的资源或工程文件。                                                  |
| [package.json](package.json)     | @zcode/web-share 的包信息、依赖和开发命令。                                   |
| [README.md](README.md)           | 本目录用途、子目录与逐文件说明。                                              |
| [vite.config.ts](vite.config.ts) | BigModel 授权入口必须跟随 ZCODE_ENV，否则测试环境会把测试账号带到生产授权页。 |
