## 目录与文件

| [preflight.ts](preflight.ts)   | 实现或公开接口：preflight。                                 |
| [project.ts](project.ts)       | 实现或公开接口：discover、create、bundle、source。          |
| [README.md](README.md)         | 本目录用途、子目录与逐文件说明。                            |

| [sim.ts](sim.ts)               | 实现或公开接口：list、parseSimulators、isIosRuntime、pick。 |
| [ui.ts](ui.ts)                 | 实现或公开接口：status、tap、swipe、typeText。              |
